<task type="checkpoint:human-verify" gate="blocking">
  <what-built>Cross-app session sharing (XAUTH-01, XAUTH-02, XAUTH-03)</what-built>
  <how-to-verify>
**Test 1: Session sharing from treater to other apps**
1. Clear all localhost cookies
2. Go to http://localhost:3002/auth/sign-in (treater)
3. Sign in with test account
4. Verify redirected to /dashboard and authenticated
5. Open new tab: http://localhost:3001 (generator)
   - Expected: Should be authenticated (not show sign-in page)
   - Check: User name/email appears in header or dashboard
6. Open new tab: http://localhost:3003 (trucking)
   - Expected: Should be authenticated
   - Check: User name/email appears in header or dashboard

**Test 2: Session sharing from generator**
1. Sign out from all apps (or clear cookies)
2. Go to http://localhost:3001/auth/sign-in (generator)
3. Sign in with test account
4. Open new tab: http://localhost:3002 (treater)
   - Expected: Should be authenticated
5. Open new tab: http://localhost:3003 (trucking)
   - Expected: Should be authenticated

**Test 3: Session sharing from trucking**
1. Sign out from all apps (or clear cookies)
2. Go to http://localhost:3003/auth/sign-in (trucking)
3. Sign in with test account
4. Open new tab: http://localhost:3001 (generator)
   - Expected: Should be authenticated
5. Open new tab: http://localhost:3002 (treater)
   - Expected: Should be authenticated

**Test 4: Sign out propagation**
1. While authenticated on all apps
2. Sign out from treater app
3. Refresh generator tab
   - Expected: Should be signed out (redirect to sign-in)
4. Refresh trucking tab
   - Expected: Should be signed out

Record results: PASS or FAIL with details for each test.

<task type="checkpoint:human-verify" gate="blocking">
  <what-built>Organization-based routing (XAUTH-04)</what-built>
  <how-to-verify>
**Test 5: Auto-redirect based on org type**

This test requires a user with organizations of different types. If needed:
- Create a generator organization in treater app (it creates a user with generator org)
- That user's active org will be the generator org

Steps:
1. Sign in as user whose active organization is type "generator"
2. Navigate to http://localhost:3002/dashboard (treater app)
   - Expected: Should redirect to http://localhost:3001/dashboard (generator app)
3. Check URL after redirect - should be on port 3001

**Test 6: Auto-redirect for hauler org**
1. Sign in as user whose active organization is type "hauler"
2. Navigate to http://localhost:3001/dashboard (generator app)
   - Expected: Should redirect to http://localhost:3003/dashboard (trucking app)
3. Check URL after redirect - should be on port 3003

**Test 7: No redirect for correct org type**
1. Sign in as user whose active organization is type "treater"
2. Navigate to http://localhost:3002/dashboard (treater app)
   - Expected: Should stay on treater app, no redirect
3. Navigate to http://localhost:3002/dashboard directly
   - Expected: Should stay on port 3002

**Test 8: Auth pages exempt from redirect**
1. Sign in as user with generator org type
2. Navigate to http://localhost:3002/auth/sign-in
   - Expected: Should NOT redirect (auth pages are exempt)
   - Page should redirect to dashboard since authenticated, but not cross-app

**Test 9: No redirect loops**
1. Navigate between apps rapidly
2. Check that no "too many redirects" error occurs
3. Each redirect should land on final destination without looping
