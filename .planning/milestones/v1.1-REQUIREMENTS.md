# Requirements: Hospital Waste Management v1.1

**Defined:** 2026-01-21
**Core Value:** Treaters can manage their complete waste tracking ecosystem — creating and overseeing generators and haulers with role-based access control — ensuring regulatory compliance and operational visibility.

## v1.1 Requirements

Requirements for Authentication + Organization Management milestone.

### Authentication

- [x] **AUTH-01**: Treater can sign up with email and password
- [x] **AUTH-02**: Treater receives email verification after signup
- [x] **AUTH-03**: Treater can log in with email and password
- [x] **AUTH-04**: User session persists across browser refresh
- [x] **AUTH-05**: Generator user can log in (account created by treater)
- [x] **AUTH-06**: Hauler user can log in (account created by treater)
- [x] **AUTH-07**: User can reset password via email link

### Organization Management

- [x] **ORG-01**: Treater creates generator organization with initial owner
- [x] **ORG-02**: Treater creates hauler organization with initial owner
- [x] **ORG-03**: Treater views list of their generators
- [x] **ORG-04**: Treater views list of their haulers
- [x] **ORG-05**: Treater can view generator organization details
- [x] **ORG-06**: Treater can view hauler organization details

### Team Management

- [x] **TEAM-01**: Org owner can invite team members via email
- [x] **TEAM-02**: Invited user receives email with signup/join link
- [x] **TEAM-03**: Org owner/admin can assign roles (owner, admin, member)
- [x] **TEAM-04**: Org owner/admin can remove team members
- [x] **TEAM-05**: Team member list shows name, email, role, status

### Access Control

- [x] **RBAC-01**: Owner role has full access including billing
- [x] **RBAC-02**: Admin role can manage team and settings
- [x] **RBAC-03**: Member role can use features only
- [x] **RBAC-04**: Role-based UI shows appropriate features per role
- [x] **RBAC-05**: Treaters see own data + linked generators/haulers
- [x] **RBAC-06**: Generators see only their own org data
- [x] **RBAC-07**: Haulers see only their own org data

### Cross-App Authentication

- [x] **XAUTH-01**: Session works across generator app (port 3001)
- [x] **XAUTH-02**: Session works across treater app (port 3002)
- [x] **XAUTH-03**: Session works across trucking app (port 3003)
- [x] **XAUTH-04**: User redirected to appropriate app based on org type

## Out of Scope

Explicitly excluded from v1.1 milestone.

| Feature | Reason |
|---------|--------|
| Self-registration for generators/haulers | Treaters create these accounts directly |
| Hauler partnerships with multiple treaters | Haulers exclusive to one treater (simplifies access control) |
| DENR compliance documents (COT, PTT, HazwasteID) | Deferred to v1.2 (requires stable waste tracking) |
| Vision AI for waste classification | Nice-to-have, not core |
| Driver location tracking | Requires mobile app optimization |
| OAuth/SSO login | Email/password sufficient for v1.1 |
| MFA/2FA | Can add in v1.2 once core auth stable |
